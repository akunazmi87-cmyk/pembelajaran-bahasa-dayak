# **App Name**: DayakLingua

## Core Features:

- Main Navigation Hub: Central dashboard with interactive cards for learning modules (Vocabulary, Conversation, Challenges), including a welcoming audio clip in Dayak Ngaju.
- Interactive Vocabulary Explorer: Searchable dictionary displaying Dayak Ngaju words, Indonesian translations retrieved from Firestore, and linked audio pronunciations from Firebase Storage.
- AI-Powered Contextual Phrase Generator: An AI tool that creates practice phrases or sentences using selected vocabulary words to deepen understanding and application.
- Simulated Dayak Ngaju Dialogues: Engaging chat-bubble style conversations in Dayak Ngaju and Indonesian, complete with audio playback for individual lines and full dialogues from Firebase Storage.
- Dynamic Assessment Modules: Adaptive multiple-choice and fill-in-the-blank questions loaded from Firestore to test comprehension and language application.
- Progress Tracking & Feedback: Automatic scoring for challenges, immediate feedback, and motivational messages, with user scores saved to Firestore.

## Style Guidelines:

- Primary color: Fresh emerald green (#22C365), signifying growth and learning.
- Background color: Very light greenish-grey (#F0F4F2), promoting clarity and focus for reading.
- Accent color: Bright lime green (#D9E730), used for interactive elements and highlights to provide energetic contrast.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, approachable title feel. Body font: 'Inter' (sans-serif) for clear readability in definitions, dialogues, and questions.
- Use clear, minimalistic line icons that are easily recognizable and reinforce the modern, simple design aesthetic.
- Responsive card-based navigation on the homepage, dynamic chat bubbles for conversations, and clean, sectioned layouts for quizzes to ensure mobile-friendly use.
- Subtle hover effects for navigation cards and smooth transitions between sections to enhance interactivity without distracting from educational content.
